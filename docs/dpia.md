# 在线雷达与数据馈送：数据处理影响评估

本文是 UK GDPR 第 35 条下的内部评估，不是给成员看的隐私说明。成员说明在
[can-docs 隐私说明](https://docs.ceruleanavi.net/zh_CN/privacy)。

评估对象：公开数据馈送、SSE 事件流、雷达页面对它们的展示，以及按 CAN ID 查询的
航迹。控制者：JIANYUELAB LTD。个人数据存放在 JianyueLab 的服务器和基础设施上。

日期：2026-09-19。触发原因：对可识别自然人的位置做系统性、近实时的公开展示。

## 1. 处理什么

| 表面                                                                | 谁能读                       | 识别字段                       | 位置       | 其它                                                |
| ------------------------------------------------------------------- | ---------------------------- | ------------------------------ | ---------- | --------------------------------------------------- |
| `GET https://data.ceruleanavi.net/v1/data.json` 与 `GET /v1/events` | 未认证，CORS `*`             | CAN ID、客户端填报的姓名、呼号 | 模拟器坐标 | 飞行计划、频率、ATIS 文本等                         |
| `GET /api/v1/track?cid=`（雷达同源转发）                            | 未认证；can-api 侧按 IP 限流 | CAN ID、呼号                   | 航迹点     | 不含姓名、邮箱。在线取当前记录，断线后约 3 小时窗口 |

姓名来自 FSD 登录包里的 RealName，不是资料库里的邮箱。坐标是模拟器位置，不是设备 GPS。

雷达站点不持有数据库口令：航迹由本站转发到 can-api；在线名单由浏览器直读数据馈送。

## 2. 目的与必要性

目的是让飞行员、管制员和围观的人看到网上有谁、在哪、谁在管，否则连飞无法进行。公开、免登录是产品选择：雷达是全网最暴露的页面，不能因此拿到成员库。

比例：数据馈送不包含邮箱、网站密码或网络口令。航迹不带姓名。雷达不存一份自己的成员库。

仍超出「当前在线」的部分：断线后约 3 小时仍可按 CAN ID 拉航迹。这是已知残留，记在下文措施里，不在本次假装已经关掉。

## 3. 风险

- 把 CAN ID、公开姓名和位置合在一起，可以持续跟踪某个呼号对应的人在模拟世界里的活动。
- CAN ID 是顺序整数，枚举成本低。
- 数据馈送未认证、不限流、CORS `*`，便于批量采集。
- ATIS 自由文本里可能被值机员写进个人联系方式（数据馈送金样里出现过邮箱）。那是客户端写入，不是本站字段。
- 雷达页被爬、被归档后，短期位置会离开本平台的保存期限。

这些不是特殊类型数据，也不是真实航空器监视。风险来自「可识别 + 位置 + 公开」，不是来自健康或生物识别。

## 4. 已采取的措施

- 雷达不持有数据库口令；航迹转发，浏览器不同源打 can-api。
- 航迹响应不含姓名、邮箱。
- 航迹按 IP 限流（每小时 240 次量级）。
- 成员可关闭账号；关闭后 FSD 下一轮认证失败，公开名单不再出现该人。
- 成员说明已写明：连飞时呼号、CAN ID、客户端姓名和模拟器位置会被其它成员看到。

## 5. 未做、仍要跟踪

下列属于 GDPR 积压的 P2，不在本次评估里当作已完成：

- 数据馈送 / SSE 的速率限制
- 断线后停止公开航迹（或把窗口从 3 小时收短）
- 从公开名册/数据馈送中按第 21 条反对的退出机制
- 数据馈送是否继续带客户端姓名（产品决定）

在这些落地之前，残留风险是：**公开连飞位置可被未认证方系统采集**。接受该风险的前提是：这是模拟飞行网络的运行方式，成员说明已经告知，账号关闭立即退出公开面。

## 6. 结论

需要做本评估。处理有合法基础（提供连飞服务），高风险点已识别。当前措施足以把风险限制在「公开连飞所固有」的范围内；P2 三项是降低残留风险的后续，不是本评估通过的前提。
